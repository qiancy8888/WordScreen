# Installation / 安装指南

## English
1. Completely exit KOReader.
2. Back up `koreader/plugins/wordscreen.koplugin/` and `koreader/settings/wordscreen_koreader.lua`.
3. Copy the release archive's `koreader/` folder to the Kindle USB root, merging and overwriting plugin files.
4. Safely eject the Kindle and restart KOReader.
5. Open the existing two-page-per-word PDF. Find WordScreen in Tools / More tools.

Do not delete `wordscreen_koreader.lua`: it stores favorites, playback settings and spelling mistakes. The PDF does not need to be replaced.

## 简体中文
1. 完全退出 KOReader。
2. 备份 `koreader/plugins/wordscreen.koplugin/` 和 `koreader/settings/wordscreen_koreader.lua`。
3. 将安装包中的 `koreader/` 文件夹复制到 Kindle USB 根目录，合并并覆盖插件文件。
4. 安全弹出 Kindle，重新启动 KOReader。
5. 打开原来的每词两页 PDF，在“工具 / 更多工具”中打开 WordScreen。

不要删除 `wordscreen_koreader.lua`，其中保存收藏、播放设置和错题记录。无需替换原 PDF。
