# Testing status / 实机验收状态

## v0.4.3 — 2026-11-07

**Reported device:** Kindle Paperwhite 1 (PW1 / B024), firmware 5.6.1.1, KOReader 2026.07.1.

**User-confirmed checks:**

- WordScreen opens in the Tools / More tools menu while the PDF is open.
- Spelling mode starts and shows the KOReader virtual keyboard directly.
- Typed letters appear in the on-page rounded answer boxes without a visible input dialog.
- Correct spelling advances automatically.
- Incorrect spelling is saved to the mistake book and the correct answer is revealed.
- After a wrong answer, left/right swipes work again; the keyboard reopens after moving to another word.
- Original playback mode remains available.

This is a user-reported test on one PW1 device and one KOReader version. Other Kindle models and KOReader versions are not declared compatible. The 849-word / 1698-page PDF and non-default zoom/crop layouts remain unverified.

## 简体中文

**用户实测设备：** Kindle Paperwhite 1（PW1 / B024），固件 5.6.1.1，KOReader 2026.07.1。

**用户已确认通过：**

- 打开 PDF 后，可在“工具 / 更多工具”中启动 WordScreen。
- 拼写模式正常进入，并直接显示 KOReader 虚拟键盘。
- 输入字母直接显示在页面圆角方格中，不出现可见输入对话框。
- 拼写正确后自动跳转下一词。
- 拼写错误后自动写入错题本并显示正确答案。
- 拼错后左右滑动恢复正常；切换单词后键盘重新弹出。
- 原有自动播放模式仍可使用。

以上为单台 PW1 设备、单一 KOReader 版本的用户实测反馈，不代表其他 Kindle 型号或 KOReader 版本均已兼容。849 词 / 1698 页 PDF，以及非默认缩放或裁切布局尚未验证。
