# Testing status / 实机验收状态

## v0.4.5 — 2026-11-07

**Device:** Kindle Paperwhite 1 (PW1 / B024), firmware 5.6.1.1, KOReader 2026.07.1.

**User-confirmed acceptance:**
- Starting a round at `professor`, completing 20 words, intentionally answering word 21 incorrectly, then swiping once goes directly to word 22.
- The first and second words of the round (`professor`, `buyer`) no longer flash during navigation.
- The virtual keyboard opens directly and typed letters appear in the answer boxes.
- Correct spelling advances automatically.
- Incorrect spelling is saved to the mistake book and the correct spelling is revealed.
- Manual swipe after a wrong answer works and the keyboard reopens for the next word.
- Original playback mode remains available.

This is a user-reported test on one PW1 device and one KOReader version. Other Kindle models and KOReader versions are not declared compatible.

## 简体中文

**实机设备：** Kindle Paperwhite 1（PW1 / B024），固件 5.6.1.1，KOReader 2026.07.1。

**用户已确认通过：**
- 从 `professor` 开始一轮，连续完成20个单词，第21个故意答错，滑动一次直接进入第22个。
- 不再短暂闪现本轮第一个单词 `professor` 和第二个单词 `buyer`。
- 直接显示虚拟键盘，输入字母实时显示在答案方格中。
- 答对自动跳转；答错保存错题并显示正确拼写。
- 答错后手动滑动正常，下一词重新弹出键盘。
- 原有自动播放模式仍可使用。

以上为单台 PW1 设备、单一 KOReader 版本的实测反馈，不代表其他型号均已兼容。
